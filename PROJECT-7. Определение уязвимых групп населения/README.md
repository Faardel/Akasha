### Описание проекта
Пострение кластеризации и проведение статистических тестов.\
:arrow_up: [к оглавлению](https://github.com/Faardel/Akasha/tree/main/PROJECT-7.%20Определение%20уязвимых%20групп%20населения/README.md#оглавление)


### Какой кейс решаем?
Кластеризировать регионы России для определения наиболее нуждающися в помощи, а так же определить зависимости в данных.

### Краткая информация о данных
В вашем распоряжении есть данные о доходах, заболеваемости, социально незащищённых слоях населения России и другие экономические и демографические данные.\
:arrow_up: [к оглавлению](https://github.com/Faardel/Akasha/tree/main/PROJECT-7.%20Определение%20уязвимых%20групп%20населения/README.md#оглавление)

### Этапы работы над проектом
Проект включает в себя несколько этапов:

Предобработка данных;\
Очистка данных;\
Кластеризция данных;\
Описание группы нселения;\
Определение зависимостей.\
:arrow_up: [к оглавлению](https://github.com/Faardel/Akasha/tree/main/PROJECT-7.%20Определение%20уязвимых%20групп%20населения/README.md#оглавление)

### Результат
Кластеризировали данные и определили группы населения, сталкивающиеся с бедностью.\
Определили какие признаки влияют на уровень бедности в регионе.\
